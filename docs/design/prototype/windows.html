Wayfork UI prototype — Windows (variant B port)

The macOS variant B ported to Windows 11: same content, copy and rule model, only the chrome is new — a system-tray flyout instead of the MenuBarExtra popover, a single main window with a left NavigationView (Dashboard · Tunnels · Rules · General · Logs) instead of a menu-bar popover plus a separate Settings window, Win32 caption buttons and a right-click tray context menu. Tunnel details name the OpenVPN dco adapter (Wayfork-1) rather than a utun unit (spike § S3–S4); DNS/route/NRPT state stays internal. Adds the Windows-only first-run and service-missing states.

Two Windows-only states. First run: an empty Tunnels page (no popover-first onboarding as on macOS) with drag-to-import and the two add buttons. Service-missing: the analogue of the macOS helper-approval alert — but Windows has no SMAppService approval, so the failure mode is "the service is stopped / not installed", resolved by a UAC-elevated restart or repair. Shown whenever the app cannot reach \\.\pipe\wayfork.
