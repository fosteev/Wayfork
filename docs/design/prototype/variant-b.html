Wayfork UI prototype — variant B

Alternative to v1 along three axes: popover dashboard (MenuBarExtra .window) instead of a native NSMenu; sidebar Settings with tunnels expanding in place instead of toolbar tabs + master/detail; rules grouped by tunnel instead of one flat ordered table. Logs window, helper alert and Add VLESS sheet are unchanged from v1. Dark appearance shown for the popover only.
